Ý nghĩa, câu chuyện và bối cảnh lấy từ bảng địa danh trong [tài liệu nhóm](https://docs.google.com/document/d/1WqryE88CVgMAJLq1xULrtpy2IznMl32enYt3hA5XkKE/edit?tab=t.vow30oeu9xl6).
